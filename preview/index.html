GET NIGHTREEL ONLINE

Make it yours.

You're seeing the interactive preview. To enable secure accounts and private cloud libraries, follow the included README.md.

  1. Create a free Supabase project.
  2. Paste supabase.sql into its SQL editor and run it.
  3. Put your Supabase project URL and publishable/anon key into config.js.
  4. Host these files on GitHub Pages (or any static host).
  5. Share the URL! Each friend signs up for their own account.

Never put a Supabase service_role / secret key into a website.
